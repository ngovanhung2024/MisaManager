# MISA screenshot training corpus

Six screenshots explicitly supplied by the user for recognizer fine-tuning on
2026-09-17. Original PNG bytes are preserved in `images`; `annotations.json`
pins their SHA-256 values and 392 manually transcribed crops (284 unique labels).
Coordinates are native pixels: left/top inclusive, right/bottom exclusive.

All crop/label pairs were visually reviewed in `annotation-review`. An empty
numeric crop was corrected before training; an uncertain footer and truncated
product names were excluded. The review sheets are annotation aids, not tests
or accuracy measurements. Labels were not generated by OCR or invoice XML.
The review sheets were regenerated from the final `annotations.json` after
those corrections; `corrected-crop.png` also shows the corrected number.

These images and rectangles are training data only. The runtime imports no
training module and does not use these files as templates, expected text,
verification evidence or click coordinates. No files were uploaded.

The v3 run used 1,200 batches of 16, each containing eight real crops and eight
unrelated generated lines. Real crops receive full-glyph margin augmentation;
the generated lines include antialiased/ClearType text, green table text and
white captions on dark backgrounds. The vocabulary and runtime preprocessing
stay unchanged. Width buckets keep text at its original aspect ratio.

Training command (choose a new output directory for another run):

```powershell
.\.venv\Scripts\python.exe -u training\fit_ui_recognizer.py --steps 1200 --batch-size 16 --resume models\easyocr-ui-v2\latin_ui_g2.pth --output models\easyocr-ui-v3 --annotations training\data\misa-ui-v3\annotations.json --real-fraction 0.5 --freeze-batch-norm --seed 26091703 --learning-rate 0.00001
```

All 392 crops were seen, between eight and 36 times each. There are no held-out
results. Six screenshots cover only a small part of MISA; lower training loss
does not establish general accuracy or a successful MISA workflow. No tests,
simulator or MISA workflow were run. The user must check actual behavior.
